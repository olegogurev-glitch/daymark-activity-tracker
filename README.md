# Мой день — трекер активности

Статический трекер с локальным хранением и необязательной синхронизацией между устройствами через Supabase.

## Включить синхронизацию

1. Создайте бесплатный Supabase project. На бесплатном плане проект может приостанавливаться после недели низкой активности.
2. В Supabase SQL Editor выполните `supabase-setup.sql`. Таблица включает Row Level Security: каждый вошедший пользователь может читать и менять только собственную строку.
3. В Supabase Authentication настройте адрес перенаправления для сайта: `https://olegogurev-glitch.github.io/daymark-activity-tracker/`.
4. На сайте откройте «Синхронизация», укажите Project URL и публичный publishable/anon key, создайте аккаунт или войдите. Не используйте `service_role` key в браузере.
5. При первом переносе приложение покажет отдельный запрос согласия. Записи, заметки, цели и пользовательские занятия отправляются только после подтверждения.

Текущие записи этого браузера не удаляются при выходе. Вход на другом устройстве загружает данные той же учётной записи.
