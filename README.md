# Мой день — трекер активности

Статический трекер с локальным хранением и синхронизацией между устройствами через Supabase.

## Как подключиться

1. Откройте сайт и нажмите «Синхронизация».
2. Введите логин и PIN из 4 цифр и нажмите «Создать аккаунт» или «Войти». Вход по одноразовой ссылке на почту тоже остаётся: он нужен для старых аккаунтов и если забыт PIN.
3. При первом подключении подтвердите перенос записей, заметок, целей и пользовательских занятий в ваш облачный аккаунт.
4. На телефоне или другом компьютере откройте тот же сайт и войдите в тот же аккаунт.

У разных аккаунтов отдельные строки данных; доступ ограничен политиками Row Level Security. В клиенте используется только публичный publishable key. Секретный `service_role` key не используется. Секрет для проверки PIN и `service_role` key доступны только серверной функции `pin-auth`, а не сайту.

Можно записывать несколько занятий на одно время. Каждое занятие сохраняется отдельно, поэтому суммарное время на панели складывает длительность каждого занятия, включая одновременные.

## Инфраструктура

Сайт размещён на Cloudflare Pages: https://day.summershots.org/ . Адрес `daymark-activity-tracker.pages.dev` тоже работает, но открывается не на всех устройствах. Каждый push в `main` публикуется автоматически. Этот адрес указан в настройках Supabase (Site URL и Redirect URLs) и в списке разрешённых сайтов функции `pin-auth`; при смене адреса его нужно обновить в обоих местах.

Supabase project `daymark-activity-tracker` размещён в регионе Frankfurt на Free плане. Таблица `tracker_data` доступна только аутентифицированному владельцу строки. SQL для создания таблицы и политик хранится в `supabase-setup.sql`.

На бесплатном плане проект может приостанавливаться после периода низкой активности. Данные в браузере сохраняются локально; экспорт остаётся доступен как резервная копия.

В списке «Мои занятия» можно изменить цвет или удалить тип занятия. При удалении приложение покажет число связанных записей и спросит подтверждение. Удалённые записи синхронизируются как удаления, поэтому они не должны возвращаться при следующей синхронизации.

## Цветовая тема и логотип

Интерфейс использует пастельную палитру из лавандового, мятного, бирюзового и пыльно-розового оттенков. Логотип часов с цветком и отметкой сохранён как `clock-logo-pastel.png` в корне сайта; при ручном обновлении загрузите вместе с ним обновлённый `index.html`.

В недельных целях теперь можно выбрать любое занятие из списка, включая скрытые для быстрого добавления. Удаление цели синхронизируется между устройствами.

## Как работает синхронизация

Логика объединения данных находится в `sync-merge.js`, логика таймера в `timer-logic.js`, напоминание о копии в `backup-reminder.js`, а расчёты статистики в `stats.js`. Тесты запускаются командой `node --test tests/`.

У каждой записи, занятия и цели есть отметка времени последнего изменения: при расхождении побеждает более новое изменение, а при равных отметках остаётся облачная копия. Удалённая запись остаётся удалённой. Переименование занятия переносит на новое название и записи, сделанные на устройстве со старой копией. Перед записью приложение проверяет, что строка в облаке не изменилась с момента чтения; если изменилась, данные объединяются заново.

Отметки времени берутся из часов устройства, поэтому при сильно неверных часах может победить не то изменение. Синхронизация запускается при входе, после изменений, при возврате на вкладку и при появлении сети; постоянного опроса нет.

Экспорт сохраняет записи, цели и список занятий. Импорт понимает и старые файлы, где есть только записи: недостающие занятия создаются автоматически.

## Вход по логину и PIN

В Supabase нет встроенного входа по PIN, а пароль должен быть не короче 6 символов. Поэтому PIN проверяет серверная функция `supabase/functions/pin-auth`, а таблица `pin_logins` из `supabase/migrations` закрыта для обычных запросов с сайта. Каждая попытка считается до проверки PIN: после 5 неверных подряд вход блокируется на 15 минут, затем срок удваивается, но не превышает 24 часов. Правильный PIN сбрасывает счётчик. Простые PIN вроде 1234 запрещены, а новых аккаунтов может создаваться не больше 20 в час.

Развёртывание:

```bash
npx supabase login
npx supabase link --project-ref fofvjbihskblycohaltt
npx supabase db push
npx supabase secrets set PIN_PEPPER="$(openssl rand -base64 32)"
npx supabase functions deploy pin-auth --no-verify-jwt
```

Значение `PIN_PEPPER` нельзя менять: после этого все PIN перестанут подходить.

Если друг без почты забыл PIN, выполните в SQL Editor запрос ниже. В течение часа он сможет нажать «Создать аккаунт» со своим логином и новым PIN, и его данные сохранятся. Пока это окно открыто, новый PIN может задать любой, кто знает логин, поэтому открывайте его только по договорённости.

```sql
update public.pin_logins set reset_until = now() + interval '1 hour' where login = 'логин';
```

## Таймер

Выберите занятие и нажмите «Старт». Таймер можно поставить на паузу и продолжить; он не сбрасывается при перезагрузке страницы и синхронизируется между устройствами. Одновременно идёт один таймер. После «Стоп» и подтверждения занятие появляется в списке дня.

Время паузы не входит в длительность, но показывается в записи. Занятие, перешедшее через полночь, сохраняется двумя записями, по одной на день. Меньше 30 секунд работы не сохраняется.

## Ручной ввод

Форма сразу предлагает последний час, а после добавления продолжает с времени окончания предыдущей записи. Если конец раньше начала, запись считается ночной и сохраняется двумя записями, по одной на день; такой промежуток может быть не длиннее 12 часов, иначе приложение просит проверить время. Удаление записи можно отменить в течение 6 секунд.

## Фраза дня

Вверху страницы каждый день показывается новая шутливая мотивирующая фраза. Все 40 фраз находятся в `day-summary.js`; они повторяются только после того, как показаны все. При выключенных шутках фразы про диван и лень пропускаются.

## Итог дня

Приложение само пишет строку об итогах дня по записям: хвалит за сильный день, рекорд месяца, выполненную цель и серию дней подряд, а за слабый или пустой день мягко шутит. Слабым день считается по сравнению с вашими обычными днями за последний месяц и только после 19:00. Строки находятся в `day-summary.js`, и никакие данные никуда не отправляются. Шутки можно выключить в меню «⋯» отдельно на каждом устройстве.

Написанные раньше вручную строки остаются в данных и в резервной копии, но больше не показываются.

## Таймер: долгие занятия

Через 4 часа работы таймер спрашивает, продолжаете ли вы. В окне «Стоп» можно указать, когда вы на самом деле закончили, или удалить таймер без сохранения.

## Резервные копии

Приложение напоминает скачать копию, если последней не было 30 дней (на каждом устройстве отдельно). Новых пользователей оно не беспокоит первую неделю.

Кроме того, база сама хранит по одной копии данных каждого пользователя за день в течение 30 дней (`supabase/migrations/20261106120000_daily_backups.sql`). Прочитать их можно только в SQL Editor. Эти копии спасают от ошибки или неудачной синхронизации, но не от потери всего проекта, поэтому скачанные копии всё равно нужны.

```sql
select user_id, day, jsonb_array_length(data->'activities') as entries from public.tracker_backups order by day desc;
```

## Приложение на главном экране

Сайт можно установить как приложение: меню «⋯» → «Установить приложение». Файлы `manifest.webmanifest` и `sw.js` делают его доступным без интернета. Свои файлы приложение берёт из сети, а сохранённую копию использует только без связи (или если сеть не отвечает 4 секунды). Запросы к Supabase никогда не сохраняются. Изменения, сделанные без сети, отправляются при следующей синхронизации.

При возвращении в приложение оно раз в 10 минут проверяет, вышла ли новая версия, и перезагружается, если вы ничего не вводите. На iPhone установленное приложение хранит данные отдельно от Safari, поэтому в нём нужно войти один раз; ссылка из письма открывается в браузере, поэтому там лучше входить по логину и PIN.

## Статистика

Блок «Мой ритм» показывает часы по дням недели или месяца, а за всё время: по дням, пока записи охватывают меньше месяца, затем по месяцам (последние 12). Текущая неделя и месяц сравниваются с теми же днями прошлого периода, завершённые: с прошлым периодом целиком. Фильтр по занятию влияет на столбцы, итоги и сравнение.
